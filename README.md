## 报告字段

每个产品包含：产品/模型名、开发方、类型（文生/图生/编辑延展/数字人）、**10 分制主观共识评分（含区间与依据）**、官方网址（已核验域名）、免费额度（具体口径）、价格（国内人民币；海外 USD 原价 + 约合人民币，1 USD≈7.1 CNY）、一句话特点与局限，以及**每条可追溯信源 URL**（官方站点 + 科技媒体 + 用户社区/应用商店三类交叉核验）。

## 调研方法

- 三个独立调研批次并行完成国内与海外各产品的检索，再经整合去重与独立抽查复核；
- 质量评分综合 Artificial Analysis / VBench / SuperCLUE 等公开基准、科技媒体评测（机器之心/量子位/新华网/36氪/TechCrunch/The Verge 等）与用户社区（Reddit/抖音/小红书/应用商店）口碑；
- 无法核实的项一律标注"待确认"，详见各报告"关键待确认事项"章节；报告同时列有"已排除/无法核实"清单与仿冒站警示。

## 重要发现（2026-10-07 时点）

- **OpenAI Sora 已于 2026-04-26 关停**（Web/App），API 于 2026-09-24 下线，官方称无继任产品；
- **腾讯智影**已于 2025-06 暂停服务并注销公众号；**Haiper** 于 2025 年停运（团队并入微软、模型售予 NetMind.AI）；
- **Stability AI** 已无托管视频产品（SVD API 2025-07 停用，仅开源权重自托管）；**Meta Movie Gen** 从未产品化；
- 国内可灵、即梦（Seedance 2.5）、通义万相 Wan 3.0、天工 SkyReels-V4 等处于第一梯队；海外 Google Veo 3.1 与阿里 Wan 3.0（海外站）在 Artificial Analysis 文生视频榜居前。
