01调研说明与评分口径

本节先交代范围、方法与口径边界。全文所有价格、免费额度与评分数字均取自调研数据文件原文，未做四舍五入、单位换算或口径统一；换算与冲突之处一律进入第 07 节待确认清单。

调研范围 ① 文生视频：文本提示直接生成视频（含原生音频）。
② 图生视频：图片 / 首尾帧 / 参考主体驱动生成。
③ 视频编辑·延展·增强：视频重写、场景延展（outpainting / Extend）、运动控制、运镜迁移、补帧与放大、剪辑套件。
④ 数字人视频：数字人形象生成、形象克隆、多语配音与口型同步、视频翻译。
范围外：纯图像生成模型、纯剪辑工具且不含生成能力者、以及中国公司产品的国内版（国内版由国内批次负责，海外站与国内站的域名、货币与免费额度均不同）。同一产品的模型能力线或子功能（如 Runway Aleph 2.0、Stable Video 4D 2.0、Google Vids）不单列，见第 06 节。
方法论 每条产品按「官方站点 → 科技媒体 → 用户社区·应用商店」三层取证：官方定价页 / 帮助中心 / 服务条款确定价格与额度；科技媒体评测与独立实测（含 Artificial Analysis 等公开榜单）判断质量水位；应用商店评分、G2 / Trustpilot / Reddit 等用户口碑作为第三层交叉验证。
三层结论不一致处不取平均值、不臆断，一律原样并列并标注「待确认」，汇总于第 07 节。
抓取受限的官网（Luma、HeyGen、Canva、InVideo、Krea）其价格与额度以多个一致的第三方口径交叉核实，并在该条目 url_note 中注明限制原因。
五维评分维度 评分是跨来源综合的主观共识（满分 10），依据下列五个维度加权评价，各维度权重随产品形态自适应（例如数字人产品更看重形象真实度与口型同步，开源自托管产品更看重可部署性与生态）：
① 画面质量与真实感：分辨率、细节与材质、光影与电影感、人物面部一致性。
② 运动与物理一致性：时序稳定性、形变与幻觉控制、复杂运动下的一致性。
③ 指令遵循与可控性：提示词遵循度、镜头 / 运镜控制、首尾帧、编辑与延展、角色一致性、失败率。
④ 音画能力：原生音频一次生成、对白与口型同步、音效与环境声、多语配音。
⑤ 时长·分辨率·成本效率：单段时长上限、输出规格（1080p / 4K 等）、计费方式（订阅 credits / 按秒 API）与单位成本。

02重要发现

以下 8 条为本次调研中会直接改变「能不能用、能不能买」判断的结论，先于主表列出。

  • 服务关停
    OpenAI Sora 已于 2026-04-26 关停。OpenAI 于 2026-03-24 宣布关停，Web / App 于 2026-04-26 下线、API 于 2026-09-24 下线，官方明确无继任产品（无 Sora 3）；sora.com / sora.chatgpt.com 已返回 403。据媒体报道关停主因是单位经济性（推理成本高、留存与收入不匹配）。本表按历史能力保留其 8.8 分并标注「历史评分」。
  • 服务停运
    Haiper 已停运。2025-02 关闭消费级产品，两位联合创始人于 2025-03 加入 Microsoft AI（人才并购），视频模型于 2025-06 售予 NetMind.AI 用于企业推理；haiper.ai 仅剩约 6KB 的 logo 落地页，无注册、无定价、无应用。因其已无法评估当前可用性，score 为 null，本表按 JSON 原样标注「不适用」。
  • 产品形态变更
    Stability AI 已无托管视频产品。SVD / SVD-XT 仅提供开源权重自托管，托管 API 已于 2025-07-24 停用；权重自 SVD-XT 1.1（2024-02）起未再更新，已被 Wan、HunyuanVideo-I2V、LTX-Video 等开源模型超越。公司层面则完成反转：2026-08 完成 Series B 融资 7,600 万美元、累计融资约 2.32 亿美元（EA、索尼音乐、环球音乐、华纳音乐参投），估值约 10 亿美元，并赢得与 Getty Images 的英国高院版权诉讼（2025-11）。
  • 从未产品化
    Meta Movie Gen 从未产品化。2024-10 发布的研究级模型族（Movie Gen Video + Movie Gen Audio，最长 16 秒 1080p、45 秒音频），两年内始终无公开 App 或 API；Meta 未将其作为公开产品发布（无 App / 无 API / 无 GA）。Muse Image 已于 2026-07-07 上线，同源的 Muse Video 仅于 2026-07-07 预览、2026-08-19 起进入闭门 Beta，截至 2026-10-07 仍未见面向公众的全面开放（GA）；Movie Gen 与 Muse Video 的谱系关系官方未明示，故不作「能力转入」推断。故归类为「仅研究发布」，评分标注「历史评分」。
  • 仿冒站警示
    多个第三方站点冒用官方品牌：pikaslabs.com、pika-labs-ai.com 并非 Pika 官方域名（官方为 pika.art），其「免费送 150 credits/月」的说法与官网口径直接冲突；检索另现 krea.run，与官方 krea.ai 是否为镜像未能核实；Haiper 产品已停运，任何「同名」在售服务均不可信。请勿在上述站点付费或提交账号。
  • 抓取受限
    五个官网因限制无法读取正文，价格多为第三方口径：Luma（lumalabs.ai 三个地址均返回 site not supported）、HeyGen（heygen.com 抓取超时 / 被拦截）、Canva（canva.com/pricing 被 robots.txt 拒绝）、InVideo（invideo.io/pricing 工具报 site not supported）、Krea（krea.ai 抓取受限）。上述条目的价格与免费额度均标注「待确认」，建议在浏览器内以结算页复核。
  • 口径冲突
    Pika 免费额度两套口径互斥：官方 pika.art/pricing 显示 Free 为 $0 且「0 credits/月 · packs only」，而第三方站称「免费送 150 credits/月」。同类冲突还有 Canva 免费视频额度、Kling「每日 66 免费积分」、Hailuo 免费档、LTX Studio 与 PixVerse 免费档，均见第 07 节。
